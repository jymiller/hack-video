The Thursday stack

Five sponsors, none of them in the library. Judged by the desk’s own test: can you point at it doing a distinct thing on screen?

The vendor test, unchanged

A vendor earns a slot only if somebody can point at it doing a distinct thing on screen. Not a capability — an event. Every vendor costs integration time that would otherwise be build time, and with 3h30m that trade is brutal. A sponsor prize never argues one back in.

The one you asked about

TwelveLabs

Use · the centre of the build Video understanding — indexes video and makes it searchable across what is seen, heard and said
What it actually does
Two models. Marengo is the encoder — it turns video into embeddings you can search. Pegasus is the video-language model — it answers questions about a clip in words. You create an index, upload video, wait for it to process, then query it.
The three modalities
Visual — actions, objects, events, brand logos, and text on screen through OCR. Audio — ambient sound, music, effects. Transcription — the spoken words. The OCR is the part that makes our reconciliation possible, and it is not the obvious reason to reach for this product.
Watchable moment
The agent jumps the playhead to the exact second the evidence appears — 04:12, the reporter says the number, and the lower third confirms it. The video scrubs itself to the proof.
Why that passes
It is an event, not a capability. A stranger sees a video seek itself to a moment somebody just asked about, and understands instantly that the machine watched it. Nothing needs captioning.
Needs
An account and an API key. No credit card for the free tier.
Free: 600 min total indexing + analysis + segmentation share the 600 Paid: $0.042/min index $4 per 1,000 searches Free index data cleared after 90 days
Two things about TwelveLabs that could cost the day

Model slugs drift, and one already has. Marengo 2.7 was sunset on 30 March 2026 — you can no longer index or search with it. This is trap 11 in the desk’s own handoff: pull the model list before trusting a slug. Copying a code sample off a blog post written last year is a live way to lose an hour on Thursday.

Indexing time is still the number we do not have. 600 free minutes is comfortably enough for four news clips. How long those minutes take to process is the open question, and it is the single most likely way a 3h30m build ends with nothing on screen. One clip indexed and timed tonight settles it.

The rest of the stack

And the one nobody expects to be a problem

Neo4j

Conditional The graph database the findings are written into
The problem
You know what it is, so I will only flag the trap. A graph blooming on screen is a chart redrawing, which this desk refuses outright — it needs a caption to be understood and it is indistinguishable from any network diagram in any demo. Judges have seen a hundred of them.
Watchable moment
A single path lighting up, one hop at a time, from a night in December to a ratio in a bond covenant — with each hop named aloud as it fires.
Why the distinction matters
The subject is the path, not the graph. A path is a story with a direction and an ending. A graph is wallpaper. This is the same conclusion the desk reached about DataHub’s lineage view yesterday, and it holds here for the same reason.

Strands Agents

Conditional · use it anyway AWS’s open-source agent SDK — Python and TypeScript, model-agnostic, MCP built in
What it is
AWS’s answer to CrewAI. You define a model, some tools and a prompt; it runs the reasoning loop, tool calls and conversation state. Native Bedrock integration but it works with Anthropic, OpenAI and Gemini too, so nothing is locked. Multi-agent patterns and OpenTelemetry tracing are built in.
Watchable moment
None. A framework is invisible by nature, and by the vendor test alone it would be cut.
Why it stays anyway
Because AWS is hosting and judging. This is the same logic as “Use of DataHub” being the first criterion on 10 August — at a sponsor event, using the sponsor’s framework is scored whether or not anyone can see it. It also speaks MCP, which is how it would reach Neo4j.
Open sourcePython + TypeScriptMCP native~6,500 GitHub stars

OpenAI

Use — but for the voice The reasoning layer over the graph
As reasoning
Invisible. Nobody can point at a model thinking, and on the vendor test alone that is a cut.
As voice
It speaks the finding out loud over the footage. That is the watchable moment — the one this desk has actually won on, and the channel almost nobody at a video hackathon will use.
The trap
Text-to-speech fails silently. A bad voice id returns HTTP 200 and produces nothing, or the wrong voice. Hash the output and listen to it — never trust the status code. This is a paid-for lesson in the desk’s record.

AWS

Cut as a vendor · it is the venue Host, and the Builder Loft is the room
Watchable moment
None. Infrastructure is invisible by definition, and a console screenshot is not an event.
How it earns its place instead
Through Strands, which is AWS’s. Adding Bedrock or a hosted deployment on top would cost build time for something no judge sees — and at 3h30m that is the trade we cannot afford.

The decision this forces

Strands or CrewAI

Strands

The sponsor’s own framework, at the sponsor’s own venue, judged by their people. MCP native, so Neo4j and TwelveLabs both reachable. The cost is that it is new to us and the learning happens inside a 3h30m window.

CrewAI

What the desk already runs, with every trap already paid for — the listener bug, the provider routing, the model pinning. Faster and safer, and invisible to a judge either way, but it uses none of the sponsor’s stack.

The honest read: learn Strands tonight, not Thursday. An hour on Wednesday building a hello-world agent with one tool decides it. If that hour goes badly, CrewAI is the fallback and nothing is lost.
